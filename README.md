# FluxDevvOS update shelf

## Download and install FluxDevvOS

**Windows installer: [FluxDevvOS-Setup-0.1.0-personal.10.exe](./FluxDevvOS-Setup-0.1.0-personal.10.exe)**

1. Click the **`.exe` installer** in the file list above, or use the installer link here.
2. On its GitHub file page, click **Download raw file** (the downward-arrow download icon near the top right). If GitHub shows **View raw**, you can use that link instead. A message saying the file is too large to preview is normal; you can still download it.
3. Save the `.exe`, then open it from your **Downloads** folder and follow setup.
4. Open **FluxDevvOS** from the Windows Start menu, create your own local profile, and complete the tool setup for your role.
5. Connect your own Claude Code or Codex account. No owner approval or shared Wi-Fi is required.

**Shortcut:** [Download the installer directly](./FluxDevvOS-Setup-0.1.0-personal.10.exe?raw=true).

Download the **`.exe`**, not `latest.json`. You do not need **Code → Download ZIP**, Git, or a terminal command to install the app.

This is an **unsigned Windows beta**, so Windows may show a publisher warning. If you are unsure about a warning, stop and ask the person who sent you this official shelf link; do not disable your security software.

## Updates and privacy

Installed copies of FluxDevvOS check `latest.json` here and download the newest installer.
The note is sealed with the publisher's key; a copy installs only an installer whose size and
SHA-256 match it. This shelf holds the app's installer only, never anyone's projects or data.
